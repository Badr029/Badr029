### 🚀 About Me

Backend Developer and QA Engineer with hands-on experience building and testing scalable web applications and   
APIs. Independently designed, developed, and fully tested two production-ready platforms — StatusPulse (Node.js,   
Express, PostgreSQL, Docker) and ScoutPro (Laravel, Angular, MySQL) — acting as sole developer and tester on   
both: architecting REST APIs, designing database schemas, implementing background schedulers, and running   
complete QA processes including Selenium automation, Jest unit tests, and Postman API testing. Brings a rare   
combination of development depth and quality assurance rigor.
