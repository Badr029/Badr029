### About Me

**I'm a QA Engineer with a backend development background, currently working in Software Quality Assurance at Baims.** I test mobile and web applications through manual testing, automation, API investigation, and regression testing.

I earned my **ISTQB Certified Tester Foundation Level (CTFL v4.0)** certification in November 2026. My development experience helps me follow a feature through its UI, API, and database, investigate the cause of a defect, and write a bug report developers can act on.

I also built and tested four independent full-stack systems. My project work covers manual test design, API testing, Selenium E2E automation, unit and integration testing, CI, and performance testing. I publish case studies and recorded results in my portfolio.
